# Run for Tibet

Run for Tibet is a 50km/100km virtual running challenge website. This repository is organized as a monorepo with a FastAPI backend and a React/Vite frontend.

## Project Structure

```text
.
├── backend/   # FastAPI application scaffold
└── frontend/  # React + TypeScript + Vite application scaffold
```

## Backend

Planned stack:

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Pydantic

## Frontend

Planned stack:

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
